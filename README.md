# Demiryol Bilim ve Kültür Kulübü

[Web sitesini ziyaret edin](https://ilyasilmek.github.io/bilimkultur/)

Orijinal kulüp logosu ve fotoğraflarıyla hazırlanan, mobil uyumlu web sitesi.

- Ana sayfa, etkinlikler, projeler ve Ar-Ge, hakkımızda, iletişim
- Kaydırma animasyonları ve yumuşak geçişler
- Hareket azaltma tercihine uyum
- Türkçe içerik ve erişilebilir mobil menü

## Düzenleme

Site `docs/` klasöründedir. HTML, CSS ve JavaScript dosyaları doğrudan düzenlenebilir; paket kurulumu gerekmez. SVG görsel dosyaları orijinal JPEG dosyalarını kayıpsız olarak içerir.

## GitHub Pages

Settings → Pages → Source: GitHub Actions. `main` güncellemeleri otomatik yayınlanır. Alternatif olarak Deploy from a branch → main → /docs seçilebilir.

Yerel önizleme için üst klasörde `bilimkultur` adlı bir klasöre `docs/` içeriğini kopyalayın ve üst klasörde `python -m http.server 8000` çalıştırın. `/bilimkultur/` adresini açın.

Görseller ve kulüp içerikleri demiryolbilimkultur.com.tr sitesinden alınmıştır.
